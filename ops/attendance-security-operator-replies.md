# Jawaban Cepat Operator Attendance Security

Gunakan template singkat ini untuk menjawab pegawai yang mengalami kendala setelah policy perangkat terdaftar diaktifkan.

## User Tidak Bisa Absen dari HP Lain

Absensi sekarang terikat ke perangkat yang terdaftar. Jika Bapak atau Ibu menggunakan HP berbeda, sistem akan menolak absensi. Silakan ajukan reset perangkat terlebih dahulu atau hubungi admin untuk dibantu.

## User Bisa Login Tetapi Absensi Gagal

Login masih bisa terbuka, tetapi saat absensi sistem memeriksa kecocokan perangkat dan lokasi realtime. Mohon kirim screenshot error dan Ref ID jika muncul agar kami cek apakah ini masalah perangkat terdaftar atau GPS.

## User Ganti HP

Jika ganti HP, perangkat lama harus di-reset lebih dulu. Setelah reset, silakan login kembali dari HP baru dan lakukan absensi agar perangkat baru terdaftar.

## User Memakai Browser Desktop

Absensi tidak diperbolehkan melalui browser desktop. Mohon gunakan aplikasi ABSENSIKU di Android atau Safari di iPhone sesuai kebijakan yang berlaku.

## User Memakai iPhone

Untuk sementara absensi di iPhone masih diperbolehkan melalui Safari. Namun perangkat tetap akan terikat ke akun Anda, jadi jika sebelumnya akun terhubung ke perangkat lain bisa perlu reset perangkat terlebih dahulu.

## Informasi Minimum yang Harus Diminta Operator

- nama akun
- organisasi atau tenant
- perangkat yang dipakai
- screenshot error
- Ref ID jika muncul
