Tutorial AbsensiKu: Admin Organisasi dan Pegawai

Dokumen ini memandu alur utama penggunaan AbsensiKu dari registrasi admin organisasi, setup absensi, operasional harian admin, hingga penggunaan oleh pegawai.

Absensi tetap menjadi fondasi utama produk. Modul HR dan Payroll berada di dalam aplikasi sebagai jalur lanjutan setelah organisasi stabil pada operasional absensi inti. Tutorial ini tetap fokus pada fondasi absensi agar onboarding awal lebih cepat dan jelas.

Prasyarat

  1. URL aplikasi aktif, contoh: http://127.0.0.1:5173.
  2. Admin organisasi memiliki email aktif.
  3. Data master minimum sudah disiapkan (OPD/unit/lokasi kerja sesuai kebutuhan).
  4. Pegawai menerima akun (via undangan/admin) untuk login.

A. Tutorial Admin Organisasi

1) Buka Login Admin Organisasi

Akses halaman /org/login. Tab Masuk digunakan untuk admin yang sudah memiliki akun.

Gambar 01 - Login Admin Organisasi

2) Daftar Organisasi (Admin Baru)

Pilih tab Daftar Organisasi, isi data organisasi, lalu submit. Setelah berhasil, lanjut login admin.

Gambar 02 - Daftar Organisasi

3) Masuk Dashboard Organisasi

Gambar 03 - Dashboard Organisasi

Buka /org/onboarding, lalu lengkapi konfigurasi tenant dan preferensi operasional.

Buka /org/schedule/work-hours, atur jam masuk/pulang, toleransi terlambat, dan aturan shift.

C. Checklist Go-Live

  1. Jam kerja dan aturan absensi sudah ditetapkan.
  2. Lokasi kerja/radius sudah diverifikasi.
  3. Data pegawai aktif bersih dari duplikasi.
  4. Undangan pegawai terkirim dan teraktivasi.
  5. Alur approval permohonan sudah berjalan.
  6. Kanal bantuan (FAQ + tiket) sudah diinformasikan ke user.
