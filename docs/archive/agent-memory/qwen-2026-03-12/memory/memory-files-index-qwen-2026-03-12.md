## 📝 FORMAT BAKU MEMORY FILES

### **Prefix:**
- `[QWEN]` - Dibuat oleh Qwen Code
- `[CODEX]` - Dibuat oleh ChatGPT

### **Pattern:**
```
[QWEN] Implementasi <area> - <hasil>
[QWEN] Refactor <area> - <hasil>
[QWEN] Perbaikan <area> - <hasil>
[CODEX] Audit <area> - <temuan>
[CODEX] Review <area> - <temuan>
[CODEX] Sinkronisasi <area> - <hasil>
```

### **Area Spesifik:**
- `/org/hr`
- `/admin/hr`
- `sidebar`
- `route`
- `permission`
- `dokumentasi`
- `e2e`
- `database`
- `migration`
