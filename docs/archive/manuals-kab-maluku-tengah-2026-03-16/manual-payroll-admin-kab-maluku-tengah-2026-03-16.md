# Manual Operasional Payroll Admin - Kab. Maluku Tengah

Tanggal: 16 Maret 2026

## Tujuan
- Panduan operasional admin untuk modul PAYROLL lengkap dengan gambar dan langkah kerja.

## Prasyarat
- Login sebagai admin organisasi (Kab. Maluku Tengah).
- Akses menu PAYROLL aktif di sidebar.

## Glosarium
- **Periode Payroll**: Rentang waktu penggajian tertentu.
- **Kebijakan Payroll**: Aturan utama perhitungan gaji.
- **Input Variabel**: Komponen gaji bersifat variabel (lembur, bonus, dll).
- **Validasi Payroll**: Pengecekan kelengkapan data sebelum run.
- **Run Payroll**: Eksekusi perhitungan payroll.
- **Approval Payroll**: Persetujuan hasil run payroll.
- **Slip Gaji**: Dokumen rincian gaji per pegawai.
- **Pembayaran Payroll**: Proses pembayaran gaji.
- **Pajak & Kepatuhan**: Pelaporan pajak dan compliance.
- **Audit Log**: Jejak aktivitas payroll.
