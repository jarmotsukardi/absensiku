# Bantuan Kebijakan Keamanan Absensi

Dokumen ini menjelaskan kebijakan akses absensi saat organisasi mengaktifkan device binding, blok browser tertentu, dan validasi lokasi realtime.

## Perubahan Kebijakan Akses Absensi

Untuk meningkatkan keamanan dan mencegah penyalahgunaan absensi, akses absensi pegawai dibatasi pada perangkat yang terdaftar.

Ketentuan yang berlaku:
- pegawai Android wajib menggunakan aplikasi atau WebView internal ABSENSIKU
- akses melalui browser desktop tidak diperbolehkan untuk absensi
- pengguna iPhone untuk sementara dapat menggunakan Safari
- lokasi perangkat harus aktif dan realtime saat melakukan absensi
- jika pegawai berganti perangkat, diperlukan proses reset perangkat sebelum absensi dapat dilakukan kembali

Jika Anda mengalami kendala, hubungi admin atau operator organisasi dan sertakan screenshot error serta Ref ID jika tersedia.

## Pertanyaan yang Sering Muncul

### Kenapa saya tidak bisa absen dari HP lain?

Absensi terikat ke perangkat yang terdaftar. Jika Anda memakai HP yang berbeda, sistem dapat menolak absensi untuk mencegah titip absen dan penyalahgunaan akun.

### Kenapa saya bisa login tetapi absensi gagal?

Dashboard masih bisa terbuka, tetapi saat absensi sistem memeriksa kecocokan perangkat dan lokasi realtime. Jika perangkat berbeda atau lokasi tidak valid, absensi dapat ditolak.

### Apa yang dimaksud perangkat terdaftar?

Perangkat terdaftar adalah HP atau perangkat yang pertama kali dipakai untuk absensi setelah fitur keamanan perangkat diaktifkan.

### Apakah saya bisa ganti HP?

Bisa. Sebelum absensi dari HP baru, Anda perlu melakukan reset perangkat terlebih dahulu melalui operator atau menu reset device jika fitur itu tersedia pada akun Anda.

### Kenapa lokasi atau GPS harus aktif?

Karena absensi mewajibkan lokasi realtime. Jika lokasi tidak aktif, tidak akurat, atau terdeteksi tidak realtime, absensi bisa ditolak.

### Saya pakai iPhone, apakah tetap bisa absensi?

Untuk sementara absensi di iPhone masih diperbolehkan melalui Safari, sesuai kebijakan organisasi yang aktif. Perangkat tetap akan terikat ke akun Anda.

### Apa yang perlu saya kirim ke admin jika absensi gagal?

Sertakan informasi berikut:
- nama akun
- perangkat yang dipakai
- screenshot error
- Ref ID jika muncul
