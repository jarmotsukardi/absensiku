## Risiko tersisa
- Recovery koneksi pada emulator membutuhkan re-enable jaringan eksplisit (`svc wifi/data enable`) setelah mode pesawat dimatikan; perlu diuji lagi di device nyata untuk memastikan perilakunya konsisten.
- Sentuhan manual di area tombol merah `Keluar` pada emulator masih sensitif; tap yang terlalu lama dapat memicu seleksi teks sebelum logout terkirim.
- UAT ini masih memakai override geolokasi via WebView DevTools / Chrome DevTools Protocol karena injeksi GPS ADB tidak tersedia pada emulator Genymotion yang aktif di sesi ini.

## Tindak lanjut
- Jika UAT emulator dilanjutkan, fokus berikutnya sebaiknya bergeser ke hardening atau verifikasi device nyata karena jalur absensi manual inti sudah lengkap.
- Pertahankan jadwal kerja tenant uji atau siapkan akun/jadwal aktif lain agar jalur `Absen Masuk` tetap bisa dipicu pada sesi berikutnya.
- Jika perlu, tambahkan instrumentation test Android untuk skenario `offline -> reconnect -> retry` agar kontrak UI native ini terkunci di CI.
