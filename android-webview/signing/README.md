# Signing Assets

Folder ini menyimpan artefak signing Android yang tidak perlu memenuhi root `android-webview`.

Isi saat ini:

- `absensiku-release.keystore`
- `absensiku-release-v101.keystore`

Catatan:

- File di folder ini bersifat sensitif dan sebaiknya tidak diperlakukan sebagai artefak biasa.
- Untuk hygiene jangka panjang, pertimbangkan rotasi dan pemindahan ke secret storage yang lebih aman di luar workspace kerja umum.
